# Retail-Business-Dashboard-Power-BI
An interactive Power BI dashboard built to analyze retail sales performance, profitability, and customer behavior. This project transforms raw retail transaction data into meaningful business insights that help improve decision-making.

---

## Project Overview

The objective of this project was to analyze retail business performance by tracking sales, profit, customer trends, and product performance.

The dashboard helps answer questions such as:

- How much total sales and profit were generated?
- Which products perform the best?
- Who are the top customers?
- Which regions contribute the highest sales?
- How has business performance changed compared to previous years?

## Dataset Description

The dataset contains retail business transactional data including:

- Orders
- Customers
- Products
- Sales
- Profit
- Categories
- Regions
- Order Dates

This dataset was used to analyze sales trends, profitability, and customer purchasing behavior.

## Tools Used

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – KPI creation and calculated measures
- **Excel** – Data preparation and validation


## Data Cleaning & Transformation

Performed data preprocessing using Power Query:

- Removed duplicate records
- Handled missing/null values
- Corrected data types
- Created date hierarchy
- Cleaned inconsistent values
- Prepared data for analysis


## Data Modeling

Built relationships between multiple tables to create an efficient data model.

Tables used include:

- Orders Table
- Customer Table
- Product Table
- Date Table

Created proper relationships for accurate reporting and analysis.


Key KPIs Created

- Total Sales
- Total Profit
- YoY Sales Growth
- YoY Profit Growth
- Total Customers
- Top Products
- Regional Performance
